# API REST - Baozi Store

Projeto desenvolvido para a disciplina de **Desenvolvimento Web Back-End** (UNINTER).
- **Aluno:** Matheus Augusto Andrziewski
- **RU:** 5237220

## Tecnologias
- Java 17
- Spring Boot 3
- Spring Data JPA
- Banco de Dados H2 (em memória) / suporte a MySQL
- Maven

## Como executar
1. Abra o projeto em sua IDE Java (IntelliJ IDEA, Eclipse ou VS Code).
2. Execute a classe `BaozistoreApplication.java`.
3. A API estará disponível em `http://localhost:8080`.
